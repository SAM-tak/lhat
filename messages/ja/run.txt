# ok = ran
ok = 走った
# type-error = an instruction was given the wrong type
type-error = 命令に渡された型が違う
# not-callable = this is not a subroutine
not-callable = これは呼べるものではない
# arity = the wrong number of arguments
arity = 引数の数が違う
# stack-overflow = the calls went too deep
stack-overflow = 呼び出しが深くなりすぎた
# out-of-memory = out of memory
out-of-memory = メモリが足りない
# bad-key = this cannot be a key
bad-key = これは鍵にできない
# bad-format = a number^ is written through one numeric conversion; write '%d' or '%g' and no length of your own
bad-format = number^ は数の変換ひとつで書く。'%d' か '%g' と書き、長さは自分で付けない
# dead-coroutine = this coroutine has finished
dead-coroutine = このコルーチンは既に終了済み
# yield-outside = nothing is waiting for this yield^
yield-outside = この yield^ を待っているものが無い
# no-candidate = no way of calling this member takes these arguments
no-candidate = このメンバのどの呼び方も、この引数を取らない
# coroutine-not-started = resume needs start() first
coroutine-not-started = resume の前に start() が要る
# coroutine-already-started = start() only works before the first resume
coroutine-already-started = start() は最初の resume より前でしか効かない
# sealed = this table belongs to the machine; what it holds is written by the host, not from here
sealed = このテーブルは機械のものである。中身を書くのはホストであり、ここからではない
# mutable-default = a field's default lives on the prototype: an immutable value, a table of its own (each instance is given a copy), or a definition; what something else made is given inside new
mutable-default = フィールドの既定値はプロトタイプに置かれる。不変の値、そのテーブル自身（各インスタンスに複製が渡る）、または定義のいずれかである。ほかで作った物は new の中で渡す
# no-such-unit = this machine was not given the unit this require^ asks for
no-such-unit = この require^ が求める単位を、この機械は渡されていない
# tuple-arity = this call and what it called disagree on how many values come back
tuple-arity = 呼び出しと呼ばれた側とで、返る値の数が食い違っている
# tuple-unexpected = this answered several values where one was expected; pack^ makes a table of them
tuple-unexpected = ひとつを期待した所で複数の値が返った。pack^ でテーブルにできる
# panic = panic^
panic = panic^
# suspended = the slice ran out
suspended = 実行の枠を使い切った
