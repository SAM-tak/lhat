# usage = usage: lhat [option] <file> [argument...]
usage = 使い方: lhat [オプション] <ファイル> [引数...]
   ファイル無し    プロンプトから読む
   --run          プログラム全体を検査して走らせる。ファイルの後に続く語がその '...' になる
   --check        型を検査して報告する。走らせない
   既定           構文木を出す
   --tokens       代わりにトークン列を出す
   --dump-bytecode  その単位が何にコンパイルされるかを出す
   --command      入力をコマンド形式として読む
   --strict       型の誤りをコンパイル時に報告する（ファイルの既定）
   --relaxed      決まらない型は実行時の検査に委ねる（プロンプトの既定）
   --dump-host-api [file]  この駆動系が登録する物を JSON で書き出す。lhatls 用
   --dump-messages DIR  英語のメッセージを DIR の下に、出どころごとに1ファイルで書き出す。訳の元になる
   --language TAG  システムの言語ではなく、その言語で出す
   --messages DIR  実行ファイルの隣ではなく、DIR からカタログを読む
   --compile -o DIR  プログラム全体を検査してコンパイルし、すべての単位をバイト列として DIR に書く。.lton は単独でコンパイルされる
   --dump-signatures FILE  この駆動系の登録が作る署名表を書き出す
   --signatures FILE  登録の前に署名表を読む（前段の無いビルドが登録に使う物）
   --strip-debug  --compile が書く物から、局所名と捕捉名を落とす
   --dap=PORT     そのループバックポートで DAP を話すデバッガの下で走らせる（--run を含む）
   -h, --help     これを出して何もしない
   -v, --version  版を出して何もしない
