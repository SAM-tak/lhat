## Memo.md との関係

[../Memo.md](../Memo.md) は着想を溜めるブレインストーミング用のノートであり、仕様書ではない。
記述には矛盾・撤回・未決の分岐が多数含まれる。

このディレクトリの文書は Memo.md から仕様として確定できる部分を抽出し、
矛盾点を明示的な「未決事項」として切り出したもの。

Memo.md は次の3層で構成されている。本ディレクトリの文書は原則として **最新層** を基準とする。

- **最新層** — `Memo.md` L1–L377（「最新の構想」）
- **旧層** — `Memo.md` L379–L699（「以下古い構想」以降）。撤回済みだが経緯として保存
- **末尾追記** — `Memo.md` L701–L713。旧層の後ろに置かれているが内容は新しい可能性があり、
  最新層と衝突する箇所がある

## 記法

各文書では、記述の確からしさを次のラベルで区別する。

- **［確定］** — Memo.md 最新層から一意に読み取れる。実装してよい
- **［提案］** — Memo.md に記述がなく、本文書で新たに提案するもの。承認が必要
- **［未決］** — Memo.md 内で矛盾している、または明示的に保留されている。決定が必要

未決事項には番号を振り、各文書に一覧を置く。
番号は文書ごとに接頭辞を変え、複数文書を並べて議論しても取り違えないようにする。

- `01-lexical-structure.md` — `Q1`, `Q2`, …
- `02-syntax.md` — `S1`, `S2`, …
- `03-compilation-pipeline.md` — `P1`, `P2`, …
- `04-errors.md` — `E1`, `E2`, …

いったん起票した番号は、決定後も欠番にせず決定内容を記録して残す。
後から「なぜそう決めたか」を追えるようにするため。
