## 記法

各文書の本文は **現行仕様のみ** を記述する。無印の記述はすべて確定事項であり、そのまま実装してよい。

例外として次のラベルだけを使う。

- **［補足］** — 論理的帰結として導かれた結論をキャッシュするために追加したもの。**[重要]ユーザーの明確な決断でない限り必ずこのラベルを付ける**
- **［提案］** — 本文書で新たに提案するもの。承認が必要
- **［未決］** — 矛盾している、または明示的に保留されている。決定が必要

未決事項には番号を振り、各文書に一覧を置く。
番号は文書ごとに接頭辞を変え、複数文書を並べて議論しても取り違えないようにする。

- `01-lexical-structure.md` — `Q1`, `Q2`, …
- `02-syntax.md` — `S1`, `S2`, …
- `03-compilation-pipeline.md` — `P1`, `P2`, …
- `04-errors.md` — `E1`, `E2`, …
- `05-modules.md` — `M1`, `M2`, …
- `07-language-server.md` — `L1`, `L2`, …
- `08-lton.md` — `T1`, `T2`, …
- `09-debugger.md` — `D1`, `D2`, …
- `10-localization.md` — `I1`, `I2`, …

決定済みの番号は本文から削除する。撤回・復活・大きな設計転換があったものは、
各文書末尾の「改定履歴（要約）」に1〜2行で残す。理由まで含めた詳細な経緯は残さない。
欠番になった番号は再利用しない。

### 節番号

見出しの番号は数字と `.` だけで書く。後から足した節（改訂）は、元の番号に `+` を付け、
2つ目からは `+2`、`+3` と数える。日本語は使わない。

| 見出し | 意味 |
| --- | --- |
| `### 15.1 種別は2つ` | 節 15.1 |
| `#### 15.1+ テーブルへの書き込みも…` | 15.1 への最初の追記 |
| `#### 15.1+2 レシーバだけ変異する f^` | 2つ目の追記 |

番号のない小見出しは参照されない。参照したくなったら番号を振る。

### 参照の書き方

ソースのコメントと設計文書の本文では、節を `NN§S` と書く。

- `NN` — 文書のファイル名の先頭2桁（`05` は `05-modules.md`）
- `S` — その文書の見出しの番号。章全体は `§14`、改訂は `§15.1+2`
- 文書全体は `09§`

`NN` を省くと、ソースでは 02、設計文書の中ではその文書自身を指す。

| 例 | 指すもの |
| --- | --- |
| `§15.1+` | 02 の 15.1 への最初の追記（ソース）／この文書の 15.1+（文書） |
| `05§8.8` | 05-modules.md の 8.8 |
| `01§8` | 01-lexical-structure.md の 8 章全体 |
| `03§3.1, 03§3.5` | 並べるときも1つずつ書く |

1語として書く（`05 § 8.8` のように空けない）。`の`・`章`・`改`・`Section` は使わない。

`python scripts/docrefs.py` がすべての参照を見出しと突き合わせる。
見出しの番号を変えたら、これで参照の取り残しを探す。
