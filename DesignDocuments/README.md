## Memo.md との関係

[../Memo.md](../Memo.md) は着想を溜めるブレインストーミング用のノートであり、仕様書ではない。
記述には矛盾・撤回・未決の分岐が含まれる。
このディレクトリの文書が仕様の正であり、Memo.md と食い違う場合はこちらが優先する。

## 記法

各文書の本文は **現行仕様のみ** を記述する。無印の記述はすべて確定事項であり、そのまま実装してよい。

例外として次のラベルだけを使う。

- **［提案］** — 本文書で新たに提案するもの。承認が必要
- **［未決］** — 矛盾している、または明示的に保留されている。決定が必要

未決事項には番号を振り、各文書に一覧を置く。
番号は文書ごとに接頭辞を変え、複数文書を並べて議論しても取り違えないようにする。

- `01-lexical-structure.md` — `Q1`, `Q2`, …
- `02-syntax.md` — `S1`, `S2`, …
- `03-compilation-pipeline.md` — `P1`, `P2`, …
- `04-errors.md` — `E1`, `E2`, …
- `05-modules.md` — `M1`, `M2`, …
- `06-visual-editor.md` — `V1`, `V2`, …
- `07-language-server.md` — `L1`, `L2`, …

決定済みの番号は本文から削除する。撤回・復活・大きな設計転換があったものは、
各文書末尾の「改定履歴（要約）」に1〜2行で残す。理由まで含めた詳細な経緯は残さない。
欠番になった番号は再利用しない。

### 章番号に日本語を使わない

| 例 | 可否 |
| --- | --- |
| 5.11改 | NG |
| 5.11.1 | OK |
| 5.11.a | OK |

### 章番号への参照に日本語を使わない

| 例 | 可否 |
| --- | --- |
| 02 の 5.11改 | NG |
| 5.11.a | OK |
| 02 5.11.a | OK |
| 02 §5.11.a | OK |
| 02 Section 5.11.a | OK |
