# インポートとモジュール

`import^` は、ホストアプリケーションの言語で実装され、L^ にバインド・公開されたモジュールを取り込みます。
自作アプリケーションの API も、`std.math` などの標準ライブラリも、この仕組みで利用します。
別の L^ ファイルには `require^` でアクセスします。
自分のファイルをモジュールとして使うには、`module^` で名前を宣言し、
外部に公開するシンボルに `public^` を付けます。

## ホストアプリケーションの機能を使う

ゲームのオブジェクトを操作する、アプリケーションに計算結果を渡すなど、
ホストが公開した関数や型は `import^モジュール名` で取り込めます。
使えるモジュール名と API は、組み込み先のアプリケーションが決めます。

たとえば[最小ホスト](../embedding/getting-started.md)は、C で実装した手続きを
`app` モジュールの `report` として公開しています。そのホストで動かすスクリプトが次の例です。

<<< @/../sample/embedding/main.lh{lhat}

`let^app = import^app` でホストのモジュールを取り込み、`app.report(elapsed)` でその手続きを呼び出します。
`let^host = import^app` と別名を付ければ、呼び出しは `host.report(elapsed)` と書けます。
ホストから呼ばれる `update` を `public^` で公開することで、ホストとスクリプトが互いの機能を利用できます。

この `app.report` はサンプルのホストが提供する API です。CLI でそのまま実行するには、同じ登録が必要です。
ホスト側で自作 API をバインド・登録する手順は[ホスト API と型を公開する](../embedding/host-api.md)を参照してください。
登録されたシグネチャは、L^ 側の型検査やエディタの補完にも使われます。

## 標準ライブラリも同じ仕組みで使う

`import^std.math` と書くと、その翻訳単位で `std.math` の関数や型を使えるようになります。
たとえば平方根を求める関数は `std.math.sqrt` です。

<<< @/../sample/docs/modules/import.lh{lhat}

`let^m = import^std.math` のように、好きな名前に束縛することもできます。
この場合は `m.sqrt(...)` と書けます。上の例は `9.0`、`12.0` を表示します。

標準ライブラリも、ホストが登録して公開するモジュールの一例です。
CLI では標準ライブラリを利用できますが、自作ホストでは使いたいライブラリを登録します。
自作の L^ ファイルを読み込む場合は、次の `require^` を使います。

## モジュールを宣言して公開する

`sample/docs/modules/arithmetic.lh` は、数値を2倍にする関数を公開するモジュールです。

<<< @/../sample/docs/modules/arithmetic.lh{lhat}

ファイルの先頭に `module^モジュール名` を書きます。名前は `demo.arithmetic` のように
`.` で区切れ、ファイルの置き場所とは独立しています。
このファイルのような、個別に読み込み・検査されるソースの単位を「翻訳単位」と呼びます。

宣言は既定では非公開です。`public^let^` を付けた `double` は他の翻訳単位から使えますが、
`factor` はこのモジュールの内側だけで使います。
公開したシンボルは自動的にモジュールのメンバになるため、末尾で公開用テーブルを返す必要はありません。

## 別のファイルから読み込む

同じディレクトリの `main.lh` から、`require^` で読み込みます。

<<< @/../sample/docs/modules/main.lh{lhat}

`let^calc = require^"arithmetic.lh"` は、公開されたシンボルをメンバに持つテーブルを返し、
ここでは `calc` という別名に束縛します。非公開の `factor` は取り込まれません。
パスは文字列リテラルで指定し、読み込む側のファイルを基準に解決されます。

束縛せずに `require^"arithmetic.lh"` と書くと、宣言されたモジュール名を使って
`demo.arithmetic.double(...)` と参照できます。同じモジュールを再び読み込んでも初期化は一度だけで、
同じテーブルが返ります。`require^` は初期化処理を実行するため、関数 `f^` の本体には書けません。

リポジトリのルートで次を実行すると、`42`、`10` を表示します。

```sh
lhat sample/docs/modules/main.lh
```
