# 並行処理

`std.task` は、複数の仕事をワーカースレッドで並行に実行する標準ライブラリです。
仕事を `async` で投入し、`await` で結果を受け取ります。複数コアがあれば、計算を並列に進められます。

ここではハノイの塔を例に、逐次計算からタスク分割へ進みます。
円盤の移動を実行・表示するのではなく、再帰で部分問題を解いて手数を数えます。
左右の部分問題は独立した計算なので、同時に計算して結果を足せます。

## まず逐次計算する

`sample/hanoi.lh` は、24枚の円盤に必要な手数を数える短いプログラムです。
`this^` は実行中の関数自身を指します。

<<< @/../sample/hanoi.lh{lhat}

再帰で左右の部分問題を順に解き、その間の1手を足します。結果は `16777215`（2の24乗 − 1）です。

## 2つのタスクに分ける

`sample/hanoi2.lh` は、左右の計算を2つのタスクに分けた版です。

<<< @/../sample/hanoi2.lh{lhat}

| 呼び出し | 役割 |
| --- | --- |
| `std.task.start(2)` | 2本のワーカースレッドを起動する |
| `std.task.async(...)` | 仕事を投入し、結果を受け取るための `Task` を返す |
| `std.task.await(task)` | 完了まで待ち、仕事の戻り値を受け取る |
| `std.task.stop()` | ワーカーを停止し、後始末する |

`half` の `_yield^0` は、この呼び出しを未開始のコルーチンにするための宣言です。
`half(...)` はその場で計算を終えず、`async` に渡された仕事がワーカーで実行されます。
`_yield^` 自体は実行時に中断せず、`0` も計算結果ではありません。
`async` は、引数なしで呼べる関数・手続きを直接渡す形にも対応します。

ポイントは、**2つとも `async` で投入してから `await` する**ことです。
`left` を待っている間も `right` は進められ、結果は逐次版と同じ `16777215` になります。
各呼び出しの `try^` は、起動・投入・結果取得のエラーを呼び出し元へ返します。
同じ `Task` の結果を受け取れるのは一度だけです。

## タスク数とワーカー数を分ける

`sample/hanoi3.lh` は、再帰の上5段で計算を分割し、32個のタスクを6本のワーカーに配ります。

<<< @/../sample/hanoi3.lh{lhat}

`split` が部分問題を投入し、分割の間にある1手を `moves` に加えます。
各タスクは引数で渡された部分問題を計算し、最後のループで結果を回収します。
`Task<number^>` は、結果が数値であるタスクの型です。

**タスクごとにスレッドを作る必要はありません。** ワーカーが実行待ちの仕事を順に処理します。
`workers` はワーカー数、`depth` は分割の細かさで、この例のタスク数は2の `depth` 乗です。
細かすぎる分割はタスクの作成・受け渡しの負担が増えるため、仕事量に合わせて調整します。

## 実行する

リポジトリのルートで実行します。3つとも `16777215` を表示します。

```sh
lhat sample/hanoi.lh
lhat sample/hanoi2.lh
lhat sample/hanoi3.lh
```

速度を比べる場合は同じ Release ビルドで実行してください。
実際の速度はコア数、計算量、タスクの分割方法によって変わります。
