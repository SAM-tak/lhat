# 最初のプログラム

[インストール](./installation.md)が終わったら、好きな作業フォルダで `hello.lh` を作成します。
L^ のソースファイルの拡張子は `.lh` です。

## 文字列を表示する

次の内容を保存してください。

<<< @/../sample/docs/hello.lh{text}

ターミナルで、ファイルを置いたフォルダから実行します。

```sh
lhat hello.lh
```

```text
Hello, L^!
```

`print` は値を表示する手続きです。文字列は二重引用符で囲みます。
この例と同じファイルは、リポジトリの `sample/docs/hello.lh` にあります。

## 実行せずに型検査する

```sh
lhat --check hello.lh
```

問題がなければ正常終了します。`print` は実行されないので、挨拶は表示されません。
編集したプログラムを実行する前に確認したいときに使えます。

ファイルの型検査は既定で strict モードです。
型が決まらない箇所や安全でない操作は、実行前に診断されます。

## 対話環境で試す

引数なしで起動すると、対話環境に入ります。

```sh
lhat
```

`print("Hello, L^!")` などの短いコードを入力して試せます。
対話環境では relaxed モードを使い、型が決まらない箇所を実行時に検査します。
ファイルで実行するときとは型検査の厳密さが異なります。
