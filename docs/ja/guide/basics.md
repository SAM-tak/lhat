# 言語の基本

このページでは、値を束縛し、テーブルを走査し、関数で計算する小さなプログラムを読みます。

## キーワードとコメント

L^ の構文キーワードには `let^`、`var^`、`for^` のように末尾に `^` が付きます。
通常の名前と区別されるため、`if` のような名前も自分の変数に使えます。
`#` から行末まではコメントです。

文字列やテーブルの連結には `..` または `::` を使います。
`"a" :: "b"` と `"a" .. "b"` は同じ意味です。優先順位と右結合も共通で、定義の合成や `op^` による演算子の定義にも使えます。

- `let^` は、後から別の値を代入できない束縛を作ります。

- `{ 10, 20, 30 }` はテーブルです。この例では数値の配列として使っています。
- 配列の添字は 0 から始まるので、`values[0]` は `10` です。
- `for^value in^values` は、テーブルの値を順に取り出します。
- `f^x { x * 2 }` は引数 `x` を 2 倍する関数です。末尾の式の値を返します。

`double` が返す `20`、`40`、`60` の合計が `120` になります。
この例では型注釈を書いていませんが、型検査器が使われ方から型を推論します。

::: tip 束縛とテーブルの変更は別です
`let^` は、その名前への再代入を禁止します。テーブルの内容を変更できるかどうかは、
テーブルの型や使用する文脈によって決まります。
:::

## 配列の範囲と逆順の走査

`range^(n, m)` は配列の下限 n から上限 m までを昇順、`reverse_range^(n, m)` は同じ範囲を逆順、
`reverse_iterate^()` は配列全体を降順に走査します。
どれも元の添字と値を返すイテレーター（コルーチン）で、配列のコピーは作りません。
辞書部分は含みません。

```lhat
let^ values = {10, 20, 30, 40}
for^ i, v in^ values.range^(1, 2) { print(i, v) }
# 1 20、2 30

for^ i, v in^ values.reverse_iterate^() {
    if^ v >= 30 { values.remove^(i) }
}
# values は {10, 20}
```

範囲は 0 起点で両端を含みます。負の添字は末尾から数え、`-1` が最後です。
`range^` と `reverse_range^` は下限・上限を指定し、第2引数を省略すると上限は末尾です。
開始・終了の順に指定する `range_downto^(開始, 終了)` も使えます。終了の省略時は先頭（0）です。
`reverse_range^(1, 3)` と `range_downto^(3, 1)` は、どちらも 3、2、1 の順に進みます。
下限が上限より大きい範囲や範囲外の端点は空の走査になります。
端点は呼び出し時に確定し、値は走査時点のものを読みます。`index^` は導入しません。

前向きの走査中に `remove^` すると、前詰めによって要素を飛ばすことがあります。
現在要素を削除するには、上の例のように逆順で走査してください。
逆順でも、ほかの位置の削除・挿入・並べ替えまで安全になるわけではありません。
辞書の巡回中に既存キーを `values[k] := nil^` で削除するだけなら、残りのキーは飛ばしません。
配列位置への `nil^` 代入は位置を残し、長さを減らしません。

`slice^` は浅いコピーを返し、`reverse^()` は元の配列をその場で反転します。

## 型を指定して生成する

`new^型{ フィールド=値, ... }` で、型を指定した値を生成できます。

```lhat
let^ t = new^t^{ aaa:string^ } { aaa="aaa", bbb=42 }
let^ Point = def^{ self^{ x=0, y=0 } }
let^ p = new^Point { x=10 }

errordef^ InputError { Invalid { line:number^ } }
let^ e = new^InputError.Invalid { line=3, message="invalid input" }
```

構造的なテーブル型は、生成する値が満たす制約です。追加フィールドも許し、
上の `t` は `aaa:string^` に加えて `bbb:number^` を持つ型になります。
必須フィールドの不足や、`aaa=42` のような型の不一致はエラーです。

`def^` の型では既定値を使ってインスタンスを作り、指定したフィールドを初期化します。
上の `p.y` は `0` です。`overload^new` で既定の `new()` が残る場合も使えます。
`override^new` で既定を置き換えた型には、`.new(...)` を使ってください。

エラー生成の従来の綴り `error^InputError.Invalid{ ... }` も引き続き使えます。
ただし、互換性のための旧構文であり、将来削除予定です（時期未定）。
新しいコードでは `new^InputError.Invalid{ ... }` を使ってください。
頂点型としての `error^` は引き続き使えます。

## 関数と手続き

<<< @/../sample/readme/functions.lh{text}

`discounted` は割引後の価格を計算する関数 `f^` です。
`checkout` は、その計算結果を `print` で表示する手続き `p^` です。
`checkout(100, 0.2)` は `80.0` を表示します。

関数は局所的な状態を更新できますが、外部の状態を書き換えたり、手続きを呼んだりできません。
手続きは、関数と手続きの両方を呼び出せます。
計算を関数、入出力や外部の更新を手続きに分けると、副作用の境界を型検査できます。
