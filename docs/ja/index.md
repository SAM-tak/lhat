# L^ とは

L^（elhat）は、ゲームやアプリケーションに組み込んで使うスクリプト言語です。
Lua の柔軟なテーブルやコルーチンを受け継ぎ、静的な型検査と型推論を備えています。

L^ では、テキストとビジュアルプログラミングで同じ `.lh` ファイルを扱います。
テキストで書いたプログラムをグラフとして表示し、通常のソースコードと同じように差分を確認できます。

::: warning 開発中の言語です
L^ は pre-1.0 の開発段階です。構文や API は今後変わる可能性があります。
このガイドはリポジトリの `main` の内容に合わせて更新します。
配布済みのバージョンと動作が異なる場合は、使用中のバージョンとリリースノートを確認してください。
:::

## このガイドでできること

**自分のアプリケーションに L^ を組み込みたい場合は、[組み込みガイド](./embedding/index.md)から始めてください。**
ビルドできるホストの例から、API の公開、GC とイベントループ、エディタ連携、配布まで説明します。
個々の関数は [C API リファレンス](./api/index.md)で調べられます。

言語そのものを CLI で試す場合は、次の順に進めます。

1. [インストール](./guide/installation.md)して、`lhat` を実行できるようにする。
2. [最初のプログラム](./guide/first-program.md)を書き、実行と型検査を試す。
3. [言語の基本](./guide/basics.md)で、変数、テーブル、関数と手続きを学ぶ。
4. [VS Code](./tools/vscode.md)で補完、診断、デバッグを使う。

## L^ の特徴

- `if^` や `let^` のように末尾に `^` が付く構文キーワードを使います。
- テーブルは配列、辞書、オブジェクトとして使え、配列の添字は 0 から始まります。
- 型推論を使って型注釈を抑えながら、実行前に型検査できます。
- 計算を行う関数 `f^` と、入出力や外部の状態変更を行う手続き `p^` を区別します。
- 型付きエラー、パターンマッチ、コルーチン、並行タスクを利用できます。
- C API から組み込み、ホストアプリケーションの関数や型を登録できます。

## ゲームエンジンから使う

このガイドでは、まず単独の CLI で言語を試します。
エンジンごとの導入手順は、各連携プロジェクトを参照してください。

| 連携先 | ドキュメント |
| --- | --- |
| Godot | [lhat-gdextension](https://github.com/SAM-tak/lhat-gdextension) |
| Unreal Engine（実験段階） | [lhat-UE](https://github.com/SAM-tak/lhat-UE) |

詳しい仕様は[設計文書](https://github.com/SAM-tak/lhat/tree/main/DesignDocuments)、
組み込みの実例は [C のホストプログラム](https://github.com/SAM-tak/lhat/blob/main/tests/install_smoke/host.c)を参照できます。
