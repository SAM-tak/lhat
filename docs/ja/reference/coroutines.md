# コルーチン

## 生成と状態

`yield^` を含むサブルーチンを呼ぶと、未開始のコルーチンが返ります。
呼び出した時点では、最初の `yield^` までを含めて本体は実行しません。
定義子は引き続き `f^`・`p^` であり、`c^` は型に使います。

| 操作 | 意味 |
| --- | --- |
| `c.start()` | 未開始の本体を開始 |
| `c.resume(値)` | 中断点へ値を渡して再開 |
| `c.started()` | 開始済みかを確認 |
| `c.done()` | 終了したかを確認 |
| `c.dispose()` | 破棄し、残っている後始末を実行 |

状態は未開始・中断・終了です。開始前の `resume`、開始済みへの `start` は実行時の異常です。
再開引数の有無はコルーチンの型に従います。

## yield と最終結果

`yield^式` は実行を中断し、動かしている側へ値を出します。
再開時に送られた値は `yield^` の結果として受け取れます。
`return^` の最終結果と途中の yield の値は型の上で区別します。

`_yield^式` は同じ型の情報を与えますが、実行時の中断と値の評価は生成しません。
実際に中断せず、呼び出しをコルーチン生成にするためにも使えます。

## 型の3つの位置

```text
c^{p^R -> Y -> T}
```

`R` は再開時の受信、`Y` は yield、`T` は最終結果です。
`f^`・`p^` の指定は本体の種別で、省略すると両方を許します。
空の位置は「無し」、`*` は型と個数を制約しない位置です。`any^` は値1つの型なので `*` とは異なります。
`c^` は3位置の情報を消去した上位型です。`.ResultType` は型の位置で最終結果型を取り出します。

各中断点で `R`・`Y` は一様でなければなりません。異なる中断点の型を暗黙に合併しません。
受信する名前がなければ受信型はありません。

## await^ による委譲

`await^コルーチン` は、そのコルーチンへ実行を委譲し、終了時の `T` を値として返します。
内側の yield は外側を動かす側へ届き、再開値も内側へ渡ります。
単なる呼び出しだけでは、この委譲は起きません。
コルーチンでない値を `await^` することはできません。

`await^` は言語の構文、`std.task.await(task)` は標準ライブラリの結果取得 API です。
ワーカースレッドへの仕事の投入には[並行処理](../guide/tasks.md)を参照してください。

## 関数内の制限

関数内では、その本体で作った関数コルーチンを進められます。外部から来たコルーチンを進めて副作用を持ち込めません。
関数コルーチンの型のまま外へ返すことにも制限があります。
本体が関数のコルーチンは、受信・yield・最終結果の条件が合えば手続きコルーチン型に適合します。
手続き型を通して進める操作は手続きとして扱います。

## 継続の保存

`c.save()` はフレームを保存して `costate^` の値を返し、`c.load(保存値)` はその状態へ復元します。
ローカル変数、中断位置、残っている後始末、`await^` の委譲先も保存対象です。
テーブルなどのヒープやホスト資源は巻き戻しません。復元で捨てる側の後始末は実行しません。
保存値は元のコルーチンだけに読み込めます。未開始・中断・終了の状態を保存できますが、実行中や本体を持たない走査には使えません。
通常の走査・タスク実行には開始・再開・委譲を使います。
