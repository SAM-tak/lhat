# 式と演算子

## 優先順位

弱い順です。同じ段では、特記しない限り左から結合します。

| 段 | 演算子 | 結合 |
| --- | --- | --- |
| 1 | `or^` | 左 |
| 2 | `and^` | 左 |
| 3 | `=`、`!=`、`is^`、`<`、`<=`、`>`、`>=`、`fits^` | 比較の連鎖 |
| 4 | `<=>` | 左 |
| 5 | `..`、`::` | 右 |
| 6 | `+`、`-` | 左 |
| 7 | `*`、`/`、`//`、`%`、`cross^`、`dot^`、`bitand^`、`bitor^`、`bitxor^`、`bitshift^` | 左 |
| 8 | `catch^`、`??` | 左 |
| 9 | `as^` | 左 |
| 10 | 前置の `!`、`-`、`bitnot^`、`try^`、`await^` | 前置 |
| 11 | `**` | 右 |
| 12 | メンバ、呼び出し、添字、nil 安全な後置操作、後置 `?` | 左 |

`typeof^式` は呼び出しやメンバアクセスを含む前置形式です。
複合式の型を取るときは `typeof^(a + b)` のように括弧を使います。

## 算術、論理、連結

`**` はべき乗、`//` は切り捨て除算、`%` は剰余です。
数値演算で整数に収まらない場合は実数へ広がります。ゼロ除算も実数の inf・nan へ広がります。
ビット演算には語の演算子を使い、`|`・`&` は型の合併・交差に使います。

`!`・`and^`・`or^` は真偽値の論理演算です。`and^`・`or^` は必要な側だけを評価します。
数値・文字列・テーブルの真偽値への暗黙変換はありません。
`..` と `::` は同じ連結演算子です。文字列・テーブルの連結や定義の合成に使います。

## 比較

`=` は等値、`is^` はオブジェクトの同一性、`fits^` は型への適合です。
`is^` は数値の比較には使いません。
非等値は `!=`（別綴りは `=/`・`≠`）、以下・以上は `<=`・`>=`（`≤`・`≦`・`≥`・`≧` も可）です。
比較の連鎖では中央の式を一度だけ評価します。
`<=>` は三方比較で、利用者定義型の順序比較にも使います。

## nil と安全なアクセス

| 形 | 意味 |
| --- | --- |
| `値?` | `nil^` でないかを真偽値で問う |
| `値 ?? 代替値` | 左が `nil^` の場合だけ右を評価 |
| `値?.メンバ` | 受け手が `nil^` なら `nil^` |
| `値?[添字]` | 受け手が `nil^` なら `nil^` |
| `値?(引数)` | 呼び出し先が `nil^` なら `nil^` |

これらの安全なアクセスは受け手の不在を扱います。存在する値の型違いや、任意の実行時異常を隠すものではありません。
`catch^` はエラー、`??` は `nil^` を扱い、それぞれ対象が異なります。

最初の nil 安全な操作は、同じ後置連鎖の残りも短絡します。
`a?.b.c()` で a が不在なら `.b` 以降の操作と引数評価を行いません。
括弧で切った `(a?.b).c()` は別の連鎖なので、外側の `.c()` を保護しません。
後置の不在判定 `?` は、連鎖が不在で終わった場合は偽です。

素のテーブルの連結は新しいテーブルを作り、配列部分を続けて並べ、キー付き部分を合わせます。同じ名前のキーが両側にあればエラーです。
元のテーブルを変更せず、要素は浅く共有します。
数値・文字列の組込みメンバは[数値と文字列](./numbers-and-strings.md)を参照してください。

## 演算子の定義

`def^` 内の `op^演算子 = 関数` で、算術、連結、`cross^`・`dot^`、`<=>`・`=` を定義できます。
二項演算はまず左へ問い合わせ、左が対応する引数を受け付けない場合は、末尾に `self^` を持つ右側の実装を探します。
`op^- = f^self^ -> 結果型 {…}` は単項 `-`、追加の引数を持つ形は二項 `-` です。
論理演算とビット演算は利用者が置き換えられません。
順序比較は `op^<=>`、同値比較は真偽値を返す `op^=` で拡張します。
`=`・`!=` は `op^=` を優先し、なければ `<=>` を使います。個別の大小比較や非等値は定義しません。
演算子の実装を yieldable にはできません。
