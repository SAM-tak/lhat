# 概覧

ソースの綴り、型の規則、評価と制御の規則を記載します。
読みながら試すには[言語の基本](../guide/basics.md)、ホストへの組み込みには[組み込みガイド](../embedding/index.md)を参照してください。

## 対象とする仕様

公開内容はリポジトリの `main` に追従します。リリースごとの固定版ではありません。
各ページ末尾に、整理元の設計文書と仕様ラベルを示します。
設計理由、改定履歴、提案・未決事項は仕様の規則に含めません。
実装との差が明示されている箇所は、その制限も記載します。

`print` や `std.task` など、ホストが公開する API の利用可能範囲は実行環境によります。
標準ライブラリの詳細は[標準ライブラリ](./stdlib/index.md)、使い方は[ガイド](../index.md)、
C 側の登録・実行 API は[C API リファレンス](../api/index.md)を参照してください。
