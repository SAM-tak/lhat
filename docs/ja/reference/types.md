# 型

## 基本的な型の綴り

| 型 | 対象 |
| --- | --- |
| `number^` | 整数・実数 |
| `string^` | 文字列 |
| `bool^` | `true^`・`false^` |
| `nil^` | 不在を表す値 `nil^` |
| `any^` | 任意の値を明示的に受け入れる型 |
| `t^{…}` | テーブルの構造型 |
| `f^…;`、`p^…;` | 関数・手続きの署名 |
| `c^{…}`、`c^` | 具体的なコルーチン型、情報を消去したコルーチン型 |
| `error^`、`localerror^` | 伝播可能なエラー、その場で処理するエラーの上位型 |

`any^` は書き手が指定する型であり、型推論で未決定のまま残った状態とは異なります。
`nil^` を含む型は `number^|nil^` のように合併で表します。

## 構造型と合併

`t^{x:number^, label:string^}` は、少なくともそのメンバと型を持つテーブルです。
追加メンバを持つ値も適合します。`t^{}` はすべてのテーブルに適合し、数値などには適合しません。
配列部分には `t^{number^[]}`、辞書部分には `t^{[string^]:number^}` のような型を書けます。

`A|B` はいずれかの型に適合する値です。合併から読み取れるメンバは、すべての候補が持つものです。
`A&B` は交差を表します。定義の合成に対応する型の表示にも使います。
構造が同じ通常のテーブルは、宣言名の一致を必要としません。
エラー種別・列挙体・ホストが登録した公称型などは、宣言・登録の同一性も区別します。

## サブルーチンとコルーチンの型

```text
f^引数型, 引数型 -> 戻り値型;
p^引数型;
f^引数型 -> 戻り値型1, 戻り値型2;
c^{p^再開時に受け取る型 -> yieldする型 -> 最終結果型}
```

署名の `;` は省略できません。戻り値のない手続きでは `->` を書きません。
引数名と既定値は型に含めません。署名内の `self^` は受け手の印で、型名ではありません。
`Self^` は型リテラルの内側で自身の型を参照します。
複数の戻り値はタプルです。通常の1つの変数やテーブルとは異なります。
戻り値の位置ではタプルを `-> A, B` と裸のコンマ列で書きます。`,` は `|` より弱く結合するため、合併がタプル全体を覆うときだけ `-> (A, B)|SomeError` と括弧が必要です。タプルの位置にエラー型は置けません。

ホストの公称型は `std.task.Task<number^>` のように型引数を持てます。
型引数は不変で、実行時記述子にも保持されます。

## 適合、絞り込み、キャスト

`値 fits^ 型` は真偽値を返し、分岐内で値の型を絞り込みます。
`値 as^ 型` は実行時に適合を確認し、成功なら同じ値、失敗なら `localerror^.CastFailure` を返します。
キャストは値の変換ではありません。失敗は `catch^` などでその場で処理します。
構文上互いに素と分かるキャストは型検査で拒否します。

## 型を値として扱う

`typeof^(式)` は型記述子を返し、`.signature` で型の文字列表現を得ます。
検査済みなら検査器が決定した型を使い、未検査なら実行時のタグから分かる範囲を答えます。
`number^` や `t^{…}` のような型の綴りも、型値を受け取る API に渡せます。
