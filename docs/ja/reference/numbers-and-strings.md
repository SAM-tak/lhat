# 数値と文字列

## 数値の表現と比較

型は `number^` ひとつですが、整数と実数の表現を持ちます。
整数で表せる算術は整数のまま行い、`+`・`-`・`*`・単項 `-` の桁溢れは実数へ広がります。
`**` は常に実数で、指数は整数に限りません。負の底の非整数乗などは NaN になります。
`number^.inf` は正の無限大、`number^.nan` は NaN です。数学定数は `std.math.pi`・`tau`・`e` にあります。

整数同士の比較は厳密です。実数を含む数値の等値・順序比較は、次の許容幅を使います。

```text
abs(a - b) <= (2 ** -52 * 8) * max(abs(a), abs(b), 1)
```

同じ許容帯に入る値は、小さくも大きくもない値として比較します。
この近似等値は推移律を満たしません。テーブルのキーの照合は許容幅を使わない厳密比較です。
NaN は自身とも等しくありません。

## 数値の組込みメンバ

いずれも取り込みなしで使えます。`floor^` のようなハット付きの綴りはありません。

| 呼び出し | 結果 |
| --- | --- |
| `n.tostring()` | 数値の文字列。整数と実数の綴りを区別 |
| `n.tostring(書式)` | [書式指定](./lexical.md#補間の評価と書式)に従う文字列 |
| `n.eq(相手, 許容幅)` | 許容幅に `max(abs(a), abs(b), 1)` を掛けた範囲で比較。幅0なら厳密 |
| `n.floor()` | n以下の最大の整数 |
| `n.ceil()` | n以上の最小の整数 |
| `n.round()` | 最近接の整数。ちょうど半分は偶数側へ |
| `n.abs()` | 絶対値 |
| `n.sign()` | −1・0・1 |
| `n.clamp(下限, 上限)` | 範囲に収めた値 |
| `n.isinteger()` | 値が整数で、64ビット符号付き整数に収まるか |
| `n.bitany(マスク)` | マスクのどれかのビットが立つか |
| `n.bitall(マスク)` | マスクのすべてのビットが立つか |
| `n.bitat(位置)` | 最下位を0とするビット位置。0〜63の外は偽 |

`round()` は `(2.5).round() = 2`、`(3.5).round() = 4` です。
文字列の添字を丸める規則とは異なります。
巨大な実数・無限大・NaN は、丸めてもそのままです。

## ビット演算

`bitand^`・`bitor^`・`bitxor^`・`bitshift^`・前置の `bitnot^` は64ビット整数上の演算です。
実数表現の `8.0` も使えますが、小数部のある数、範囲外、無限大、NaN は実行時に停止します。
演算結果を実数へ広げず、外へ出たビットは捨てます。
`a bitshift^ n` は正の n で左、負の n で右の論理シフトです。右シフトは空いた上位側に0を詰めます。
絶対値64以上のシフトは0です。`&`・`|`・`<<`・`>>` をビット演算には使いません。

## 文字列化

どの値も `tostring^()` を持ちます。通常の値、定義、インスタンスでは `tostring()` も同じメンバです。
素のテーブルでは裸の `tostring` は利用者のキーであり、組込みは `tostring^()` と綴ります。
`nil^`・真偽値は `nil`・`true`・`false`、文字列は引用符なしの自身を返します。
テーブル内の値はテーブルの綴りで表示します。

文字列補間の穴は `tostring^` を呼びます。差し替える実装は副作用のない `f^self^ -> string^;` に適合しなければなりません。
`..` は文字列化を暗黙には行いません。

## 文字列から数値へ

`s.tonumber()` は前後の空白を除き、符号1つと L^ の数値リテラル全体を読みます。
`0x`・`0b`・`0o`、桁区切り、小数、指数に対応し、不一致は `nil^` です。
数値の後ろのコメントや余分な文字は認めません。

`s.tonumber(書式)` は C の `scanf` 型の読み込みです。
出力と同じ数値変換 `d i o u x X f F e E g G a A` をちょうど1個含め、地の文と `%%` も書けます。
入力幅は指定できますが、出力用フラグ、精度、`*`、長さ修飾子は使えません。
書式と文字列の全体が一致する必要があります。不正な書式は panic、正しい書式で入力が合わない場合は `nil^` です。
`"ff".tonumber("%x")` は255です。

## 文字とバイト

`length`・`len` は拡張書記素クラスタ数、`size` はバイト数です。
文字の位置は0起点、範囲は両端を含み、負数は末尾から数えます。
小数の位置は `floor(x + 0.5)` で丸めます。範囲が成立しなければ空文字列です。
文字型はなく、`at()` も文字列を返します。`s[0]` による文字の参照はありません。

| 呼び出し | 内容 |
| --- | --- |
| `s.substring(開始[, 終了])`・`substr`・`sub` | 同じ切り出し。終了省略は末尾まで |
| `s.at(位置)` | `substr(位置, 位置)` と同じ |
| `s.chars()` | 拡張書記素クラスタの文字列を返す走査 |
| `s.codepoints()` | Unicode スカラー値を数値で返す走査 |
| `s.sliceBytes(開始[, 終了])` | バイト単位の半開区間 `[開始, 終了)`。文字境界を保証しない |

文字列全体を切り出す場合は元の文字列を返します。
`sliceBytes` の位置は非負整数です。負数の末尾換算や小数の丸めはせず、不正な位置は実行時の異常です。
開始が終了を越すか、範囲が末尾を越す場合は空文字列を返します。
文字列は任意のバイト列を保持します。不正な UTF-8 は `chars()` では1バイトずつ、`codepoints()` では不正バイトごとに U+FFFD として読みます。
NUL も通常の文字・コードポイント0として走査します。
全文を順に読むときは、`at()` の反復より `chars()`・`codepoints()` が適しています。

## 検索・置換・分割

| 呼び出し | 内容 |
| --- | --- |
| `s.find(針[, 開始])` | 最初の開始文字位置、または `nil^` |
| `s.findall(針)` | 非重複の開始文字位置を返す走査 |
| `s.replace(針, 置換)` | すべての一致を置換 |
| `s.split()` | 連続する空白で語に分け、空の断片を除く |
| `s.split(区切り)` | 空の断片も保持して分割。空の区切りは1文字ずつ |
| `s.toupper()`・`s.tolower()` | ASCII 英字だけの大小変換 |

針と区切りは正規表現ではなく、文字列として照合します。
元のバイト列が一致し、両端が書記素境界にある一致だけを使い、Unicode 正規化はしません。
空の針では `find` は開始位置、`findall` は空の走査、`replace` は無変更です。
区切りを指定した分割は `s.split(sep).join^(sep) = s` を保ちます。
正規表現は [std.regex](./stdlib/regex.md) を使います。
