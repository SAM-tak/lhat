# 字句とソース

## ソース形式

- 文字コードは UTF-8。ファイル先頭の BOM は読み飛ばします。
- `LF`・`CRLF`・`CR` を改行として受け付け、文字列の内部を含めて `LF` に正規化します。
- Unicode 正規化は行いません。名前はコードポイント列の一致で区別します。
- 空白は原則としてトークンの区切りです。呼び出し括弧やハットには隣接規則があります。

## 名前とハット

`^` は「ハット」です。`if` は通常の名前、`if^` は構文を表す語です。
通常の名前を予約語として取り上げることはありません。語と `^` の間に空白を挟めません。
裸の `^` は演算子ではなく、べき乗には `**` を使います。

識別子は Unicode の `XID_Start`・`XID_Continue` と `_` を基準とします。
現在の実装はこの Unicode 表を持たず、非 ASCII の文字を仕様より広く受け付けます。
通常の識別子に `?`・`!` は含められません。

バッククォートで囲むと名前リテラルになります。`` `empty?` `` のような名前を書けます。
囲みは名前に含まれず、`` `name` `` と `name` は同じ名前です。
バッククォート自体は2つ重ねます。空の名前と改行を含む名前は書けません。
`id^名前` は名前を評価せず、その綴りを文字列にします。

ハット付きの名前は言語が意味を与える位置で使います。
利用者が任意の `name^` を束縛名やメンバ名として宣言することはできません。
`self^`、`_^`、`tostring^`、`iterate^` など、仕様が認める位置は例外です。
`this^^` や `break^^` の追加のハットは外側への段数を表します。この書き方は、`this^` や `break^` など一部の識別子で使えます。

## 数値リテラル

| 形 | 意味 |
| --- | --- |
| `42`、`1_000` | 10進整数、桁区切り |
| `0x2a`、`0b101010`、`0o52` | 16進・2進・8進整数 |
| `0.5`、`1.0e-3` | 小数、指数表記 |

`.5` と `1.` は受け付けません。桁区切りの `_` は先頭・末尾・小数点の隣には置けません。
数値の直後に識別子を密着させず、`1 to^ 3` のように区切ります。
整数と実数は実行時の表現を区別しますが、言語の数値型は `number^` です。

## 文字列リテラル

| 形 | 規則 |
| --- | --- |
| `"…"` | エスケープあり。複数行可 |
| `'…'` | エスケープなし。`''` で引用符1文字。複数行可 |
| `"""` から行末 | 終端記号なし、エスケープなしの行末文字列 |
| `$"…{式}…"` | 式の文字列補間 |

二重引用符では `\n`・`\r`・`\t`・`\0`・`\\`・`\"`・`\xHH`・`\u{…}` と、
バックスラッシュに続く改行による行継続を使えます。未定義のエスケープはエラーです。
補間で `{`・`}` をそれぞれ2つ重ねると波括弧そのものを表します。`{式:書式}` の書式指定は数値用です。
穴の最上位の `:` は書式の開始なので、`if^` 式などは括弧で囲みます。
文字数とバイト数は別です。文字列のメンバは[テーブルとオブジェクト](./objects.md)を参照してください。

### 補間の評価と書式

穴は文字列を作る時点で評価し、結果の `tostring^()` を呼びます。
`{式:書式}` は数値の `tostring(書式)` と同じです。書式は式として評価せず、`:` から閉じる `}` の手前までを使います。
書式の途中に閉じ波括弧は入れられません。`$'…'` という補間文字列はありません。

書式は C の `printf` 形式で、**数値の変換をちょうど1個**含めます。

```text
%[フラグ][幅][.精度]変換文字
```

| 変換文字 | 読み方 |
| --- | --- |
| `d`・`i` | 符号付き10進整数 |
| `u` | 符号なし10進整数 |
| `o` | 8進整数 |
| `x`・`X` | 16進整数。英字は小文字・大文字 |
| `f`・`F` | 小数点形式 |
| `e`・`E` | 指数形式 |
| `g`・`G` | 有効桁数に応じた小数点形式または指数形式 |
| `a`・`A` | 16進浮動小数点形式 |

| 指定 | 意味 |
| --- | --- |
| `-` | 幅の中で左寄せ |
| `+` | 正の数にも符号を付ける |
| 空白 | 正の数の符号位置を空白にする。`+` と併用した場合は `+` が優先 |
| `0` | 幅を満たすまで0を詰める。左寄せでは無効で、整数で精度を指定した場合は精度が優先 |
| `#` | 代替形式。8進・16進の接頭辞、小数点の保持など |
| 幅（10進整数） | 最小の出力幅。値が長くても切り詰めない |
| `.精度` | 整数では最小桁数、`f`・`e` では小数桁数、`g` では有効桁数、`a` では16進小数桁数 |

大文字の変換文字は指数記号や16進の英字なども大文字にします。
小数桁数の既定は `f`・`e` では6、`g` の既定有効桁数も6です。
`g` の精度0は1として扱います。精度の数字を省略した `.` は精度0です。
`#` のない `g` は不要な末尾の0と小数点を省きます。
数値の変換文字の前後には地の文を置け、`%%` は変換数に数えず `%` を出力します。

`*` による幅・精度、長さ修飾子（`l`・`ll` など）、位置指定引数、`s`・`c`・`p`・`n` は使えません。
変換が0個・2個以上のもの、NUL を含む書式なども不正です。
不正な書式は実行時の panic で、エラー値を返すものではありません。
整数形式は実数も整数として読み（小数部は0方向へ切り捨て）、実数形式は整数も実数として読みます。
実数を整数形式で出すには64ビット符号付き整数の範囲内である必要があります。

`{n:%04d}`、`{n:%8.2f}`、`{n:n=%d%%}` のように指定します。
`{n:2.4}` のような `%` のない数値書式は使いません。
文字列化・数値化・切り出しなどの全メンバは[数値と文字列](./numbers-and-strings.md)を参照してください。

## コメント

`#` から行末までは行コメント、`#[` から `]#` まではブロックコメントです。
ブロックコメントは入れ子にできます。ブロックコメント内の引用符は区切りを無効にしません。

### 無効化コメント

`#[~` で始めて `]#` で閉じると、ビジュアルエディターが「無効化されたコード」として扱うブロックコメントになります。
実行系は通常のブロックコメントと同じく読み飛ばし、中のコードを実行・型検査しません。
言語サーバーやビジュアルエディタは、文を残したまま無効にした範囲として扱います。
無効化コメントも入れ子にでき、`#~` はこの記法ではなく通常の行コメントです。

無効化する範囲は文全体にし、注釈が付いた宣言は注釈ごと囲みます。
中の文字列にある `]#` もコメントを閉じるため、区切りの対応には注意してください。

<<< @/../sample/docs/reference/lexical.lh{lhat}

### 説明コメント

説明用の専用コメント記法はありません。宣言の前のコメントや同じ行の末尾のコメントを、エディターなどのツールが関連付けます。
無効化コメントは説明コメントのまとまりを区切り、後ろの宣言への説明としては使いません。

## 入力形式と改行

通常のソースでは呼び出しに括弧を使います。コマンド形式では、行を単位とする並置呼び出しを使えます。
通常形式の `f(x)` と、コマンド形式の `f x` は入力形式が異なります。
呼び出しの `(` は呼び出し先と同じ行に置きます。改行後の `(` を前の行への呼び出しとして連結しません。

コマンド形式が使えるのは、呼び出しとして読める行です。構文キーワードで始まる文は通常の規則で読みます。
括弧付き呼び出しは並置より強く結合します。式や文が未完の間は REPL が次の入力を待ちます。
通常形式では `f x` を括弧なし呼び出しとしては読みません。

`.` に整数キーを続ける `a.0.0` は `a[0][0]` と同じ参照です。
`1..2` は数値・連結・数値に分かれ、小数点とは読みません。
`++`・`--` は増減演算子ではありません。
ファイル先頭以外の BOM はエラーです。
