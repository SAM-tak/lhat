# 字句とソース

## ソース形式

- 文字コードは UTF-8。ファイル先頭の BOM は読み飛ばします。
- `LF`・`CRLF`・`CR` を改行として受け付け、文字列の内部を含めて `LF` に正規化します。
- Unicode 正規化は行いません。名前はコードポイント列の一致で区別します。
- 空白は原則としてトークンの区切りです。呼び出し括弧やハットには隣接規則があります。

## 名前とハット

`^` は「ハット」です。`if` は通常の名前、`if^` は構文を表す語です。
通常の名前を予約語として取り上げることはありません。語と `^` の間に空白を挟めません。
裸の `^` は演算子ではなく、べき乗には `**` を使います。

識別子は Unicode の `XID_Start`・`XID_Continue` と `_` を基準とします。
現在の実装はこの Unicode 表を持たず、非 ASCII の文字を仕様より広く受け付けます。
通常の識別子に `?`・`!` は含められません。

バッククォートで囲むと名前リテラルになります。`` `empty?` `` のような名前を書けます。
囲みは名前に含まれず、`` `name` `` と `name` は同じ名前です。
バッククォート自体は2つ重ねます。空の名前と改行を含む名前は書けません。
`id^名前` は名前を評価せず、その綴りを文字列にします。

ハット付きの名前は言語が意味を与える位置で使います。
利用者が任意の `name^` を束縛名やメンバ名として宣言することはできません。
`self^`、`_^`、`tostring^`、`iterate^` など、仕様が認める位置は例外です。
`this^^` や `break^^` の追加のハットは外側への段数を表し、任意の語には付けられません。

## 数値リテラル

| 形 | 意味 |
| --- | --- |
| `42`、`1_000` | 10進整数、桁区切り |
| `0x2a`、`0b101010`、`0o52` | 16進・2進・8進整数 |
| `0.5`、`1.0e-3` | 小数、指数表記 |

`.5` と `1.` は受け付けません。桁区切りの `_` は先頭・末尾・小数点の隣には置けません。
数値の直後に識別子を密着させず、`1 to^ 3` のように区切ります。
整数と実数は実行時の表現を区別しますが、言語の数値型は `number^` です。

## 文字列リテラル

| 形 | 規則 |
| --- | --- |
| `"…"` | エスケープあり。複数行可 |
| `'…'` | エスケープなし。`''` で引用符1文字。複数行可 |
| `"""` から行末 | 終端記号なし、エスケープなしの行末文字列 |
| `$"…{式}…"` | 式の文字列補間 |

二重引用符では `\n`・`\r`・`\t`・`\0`・`\\`・`\"`・`\xHH`・`\u{…}` と、
バックスラッシュに続く改行による行継続を使えます。未定義のエスケープはエラーです。
補間で `{`・`}` をそれぞれ2つ重ねると波括弧そのものを表します。`{式:書式}` の書式指定は数値用です。
穴の最上位の `:` は書式の開始なので、`if^` 式などは括弧で囲みます。
文字数とバイト数は別です。文字列のメンバは[テーブルとオブジェクト](./objects.md)を参照してください。

## コメント

`#` から行末までは行コメント、`#[` から `]#` まではブロックコメントです。
ブロックコメントは入れ子にできます。ブロックコメント内の引用符は区切りを無効にしません。

## 入力形式と改行

通常のソースでは呼び出しに括弧を使います。コマンド形式では、行を単位とする並置呼び出しを使えます。
通常形式の `f(x)` と、コマンド形式の `f x` は入力形式が異なります。
呼び出しの `(` は呼び出し先と同じ行に置きます。改行後の `(` を前の行への呼び出しとして連結しません。
