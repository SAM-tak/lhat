# ホスト型と箱

## ホストデータとホスト値

ホストは関数だけでなく型も登録できます。名前と署名は `import^` で取り込みます。

| 種別 | L^ から見た性質 |
| --- | --- |
| ホストデータ（hostdata） | ホストが所有する実体への参照。ファイル、チャネルなど |
| ホスト値（hostvalue） | コピーされる値。ベクトル、複素数など |

ホストデータ型は公称の同一性を持ち、登録された単一の基底型にも適合します。
同じタグと実体ポインタを持つ別ラッパーは、同じオブジェクト・キーとして扱います。
登録された `[]` はホストデータに限る添字読み出しで、返したホスト値はコピーです。
ホスト値にこの基底型・添字登録の規則は適用しません。
実体の寿命、共有やスレッド越しの受け渡しは登録した契約に従います。

## ホスト値の構築とコピー

ホスト値の型と幅は静的に決まります。値を代入・受け渡しすると、内容をコピーします。
標準の数学型は[標準ライブラリの構築関数](./stdlib/index.md#ホスト値の構築)を使い、`new^型{…}` では作れません。
`v.x` などは登録されたフィールドを読み書きします。
呼び出し結果やホストデータの添字結果の一時コピーへの書き込みは拒否します。
変更するなら局所変数に受け取り、元へ反映する必要があればホストの API で書き戻します。

## 値を置ける場所

ホスト値は型の決まった局所変数・固定引数・単一の戻り値などで扱います。
そのままテーブル要素、閉包の捕捉、`any^`、可変長引数、定義のフィールド、タプルの位置、
REPL の最上位の保持やプログラムの最終結果へ逃がすことはできません。この制限は relaxed でも変わりません。

`T|nil^` や `T|エラー種別` は、頭のタグで判別できる合併として使えます。
別のホスト値型との合併、タプルとの合併、`T|string^`、`any^` への拡大は認めません。
箱に入れる前には `fits^`・不在判定などで具体的な T に絞り込みます。

## 可変の箱

`box^値` は `T.Box^` を作ります。通常のヒープオブジェクトなので、テーブル・捕捉・`any^` などへ保持できます。

| 操作 | 規則 |
| --- | --- |
| `b.get()` | 内容のホスト値をコピーして取り出す |
| `b.set(値)` | 同じ型の内容で箱を更新 |
| `a = b` | 同じ型と内容のバイト列か |
| `a is^ b` | 同じ箱オブジェクトか |

取り出した値を書き換えても箱は変わりません。変更は `set()` で戻します。
箱には `dispose()` はありません。

## 封印された箱とキー

`constbox^値` は `T.ConstBox^` の封印されたコピーを作ります。既存の箱から作る場合も常にコピーします。
`get()` はありますが `set()` はありません。
`T.Box^` は読み取りだけの `T.ConstBox^` の要求にも適合します。
したがって `ConstBox^` という静的型だけで実体の封印を保証するものではありません。

テーブルへキーとして記録できるのは、実際に封印された箱だけです。
読み出しは可変箱や裸のホスト値でも、その時点の内容で照合できます。
型注釈を経由して未封印の箱を記録しようとした場合も実行時に拒否します。
定義の既定値の箱は、生成ごとに独立したコピーになります。
