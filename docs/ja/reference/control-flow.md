# 制御構文

## 文と式

文は処理を実行し、式は値を返します。通常のブロックで裸の計算式を文として並べることはできません。
呼び出し文、宣言、再代入、制御構文などを使います。
`f^` の本体全体が式1つだけの場合は、その式を戻り値にする規則があります。
`do^{…}` は文のブロックです。

## if^ 文と if^ 式

```text
if^ 条件 {
    文
elif^ 条件:
    文
else^:
    文
}

if^ 条件: 値 el^ 条件: 値 el^: 値;
```

- 条件は `bool^`。数値や `nil^` を暗黙に真偽値へ変換しません。
- 文形式は全分岐を1組の波括弧で囲み、値を返しません。最後の条件なしの分岐は省略できます。
- 式形式は `if^ 条件:` で始まり、`;` で閉じます。選ばれた分岐の値を返します。
- 式形式には最後の条件なしの分岐が必要です。条件の列だけから網羅性を証明しません。
- 条件付きの別綴りは `elseif^`・`else^if^`・`elsif^`・`elif^`・`ei^`・条件を伴う `el^`。
  条件なしは `else^`・`el^` です。

## パターンマッチ

```text
for^ 対象 {
when^ パターン:
    文
other^:
    文
}

for^ 対象: when^ パターン: 値 other^: 値;
```

対象は一度だけ評価し、上から最初に一致する分岐を選びます。
焦点は `it^`、または `for^let^名前 = 対象` で付けた名前から参照します。
文は1組の波括弧で閉じ、式は最後の `;` で閉じます。

| パターン | 判定 |
| --- | --- |
| `when^ 値:` | 等値 |
| `when^ 下限 to^ 上限:` | 両端を含む範囲 |
| `when^ fits^ 型:` | 型への適合と絞り込み |
| `when^ 値1, 値2:` | いずれかに一致 |
| `other^:` | 残りのすべて。`el^:`・`else^:` も可 |

文の `other^` は省略でき、一致しなければ何もしません。
式は値が必要なので網羅チェックを行います。型のパターン、真偽値の両方、列挙体の全メンバなどで
網羅を証明できる場合だけ `other^` を省略できます。数値や範囲の列だけでは証明しません。
網羅できない式は strict で型エラーとなり、検査なしで実行して一致先がなければ panic します。
パターン内の分解や、追加のガード節はありません。

## 反復と焦点

| 形 | 意味 |
| --- | --- |
| `for^i from^ a to^ b {…}` | 両端を含む昇順の数値反復 |
| `for^i from^ b downto^ a {…}` | 両端を含む降順の数値反復 |
| 上記に `step^ 幅` | 進む幅を指定 |
| `for^値 in^ 対象 {…}` | イテレーターによる走査 |
| `for^キー, 値 in^ テーブル {…}` | キー・値の走査 |
| `for^var^i = 初期値 while^ 条件 next^ 更新 {…}` | 自分で焦点を更新する反復 |
| `repeat^ n {…}` | n回繰り返す |
| `repeat^{…}` | `break^` などで抜けるまで繰り返す |
| `repeat^while^ 条件 {…}` | 条件が真の間繰り返す |
| `repeat^until^ 条件 {…}` | 条件が偽の間繰り返す |

`for^` は焦点を導入する構文であり、すべての形が反復するわけではありません。
`repeat^` は焦点を導入しません。`while^`・`until^` の条件は本体より前に判定します。
数値反復の方向は `to^`・`downto^` で明示します。

## 節と脱出

反復の節は `prolog^` → `pre^` → `first^` → `main^` → `catch^` → `last^` → `epilog^` → `finally^` の順です。
見出しのない本体は暗黙の `main^` です。

| 節 | 実行の機会 |
| --- | --- |
| `prolog^:` | 反復に入る前に1回 |
| `pre^:` | 毎回の条件判定の前 |
| `first^:` | 最初に条件が成立した反復の先頭 |
| `main^:` | 条件が成立した反復 |
| `last^:` | 条件が成立した最後の状態で、通常終了時 |
| `epilog^:` | 反復回数によらず通常終了時 |
| `finally^:` | 脱出時にも実行する後始末 |

`next^` は次の反復へ、`break^` は反復の外へ進みます。`break^^` は2段の反復を抜けます。
`next^^` も外側の反復を指定でき、`break^[2]`・`next^[2]` の数値表記も使えます。
`break^` の脱出先では `last^`・`epilog^` も実行します。
多段脱出で通過する内側の反復や、`return^`・エラー伝播による脱出では、後始末は `finally^` だけです。
`return^` は現在のサブルーチンを終了します。

## 後始末

`finally^:` はブロック末尾の節です。通常終了、`break^`、`return^`、エラー伝播、コルーチンの破棄時にも実行します。
返り値を変更できず、`f^` の本体には置けません。

`with^名前 = 式 {…}` は `dispose()` を持つ資源を束縛し、ブロックの終了時に `dispose()` を呼びます。
`with^名前 = 式` を続けて書くと、直後のブロックを共有し、定義の逆順で破棄します。

```lhat
with^r = open("data")
with^w = create("out") {
    copy(r, w)
}   # w.dispose()、r.dispose() の順
```

- 破棄は `finally^` と同じく、通常終了、`break^`、`return^`、エラー伝播、コルーチンの破棄で実行します。
- 同じブロックの `finally^` が先、`dispose()` が後です。
- 値は、引数を取らず値を返さない `dispose()` を持つ必要があります。判定は構造的で、満たさない値は strict の型検査でエラーです。
  `def^` では `dispose = p^self^ {…}` と書きます。`self^` は引数の数に入りません。標準ライブラリやホストの型も `dispose()` を持てば使えます。
- 導入する名前は `let^` と同じく再代入できません。`with^名前 := 式` も書けません。
- `f^` の本体には書けません。
- `dispose()` はエラーを返しません。失敗しうる後始末は、`flush()` などの別の操作として先に呼びます。
- コルーチンも `dispose()` を持つため、`with^` に渡すとブロックの終了時に破棄されます。
- `with^` のブロックの `catch^` 節は、初期化式の `try^` が渡すエラーを受けません。受けるには全体を `do^{…}` で囲みます。
