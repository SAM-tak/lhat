# 関数と手続き

## 定義と署名

```text
f^引数:型, 引数:型 = 既定値 -> 戻り値型 { 本体 }
p^引数:型 -> 戻り値型 { 本体 }
```

`f^` は関数、`p^` は手続きです。どちらも値として束縛し、引数や戻り値にできます。
型注釈は推論できる位置で省略できます。関数・手続きの型には末尾の `;` が必要です。
定義の本体は波括弧で閉じます。

## 呼び出しと副作用

| 規則 | 関数 `f^` | 手続き `p^` |
| --- | --- | --- |
| 呼べるサブルーチン | 関数 | 関数と手続き |
| 名前への代入 | 自分の本体が作った名前・引数 | 外側の可変な名前も可 |
| テーブルの変更 | 自分の本体が作った範囲 | 外部のテーブルも可 |

局所テーブルに外部のテーブルを格納しても、その外部テーブルを変更する権限は得ません。
型検査は入れ子の由来も考慮します。
`fresh^` は呼び出しが新しい値を返す約束、`mutable^self^` は関数メソッドが受け手を変更する約束です。
この約束を持つメソッドを関数内から呼べるかも、値の由来に従います。

副作用を許す `p^` 型には、引数・戻り値などの条件が合う `f^` の値も適合します。
逆向きは認めません。`p^` 型の値を関数から呼ぶには、関数型への絞り込みが必要です。

## 引数と戻り値

引数は本体内の名前で、再代入できます。既定値と引数名は署名の型に含めません。
可変長引数は `...:型`、型を省略すれば `any^` です。
可変長引数は末尾にだけ書け、本体の `...` は受け取った値を集めた1つのテーブルです。
呼び出しでの明示的な展開には、引数の後ろに `...` を書きます。
戻り値は `return^式`、複数なら `return^式1, 式2` と書きます。
複数の結果はタプルとして扱い、受け取り側は対応する数の名前に分解します。
`pack^呼び出し()` は複数の結果を配列テーブルにします。別の呼び出しへ渡すときも暗黙の展開はありません。

関数の本体全体が式1つだけなら、その式を返します。
この規則は複数文の末尾や手続きには広がりません。複数文の関数では `return^` を明示します。
戻り値のない手続きの署名は `p^引数型;` で、戻り値の節を置きません。

## 再帰と受け手

`this^` は現在実行中のサブルーチンです。束縛名に依存せず自己再帰できます。
`this^^` は字句上の1つ外側のサブルーチンです。
第一引数の `self^` はメソッドの受け手を表し、`値.メソッド()` で自動的に渡されます。
`Self^` は型の参照であり、受け手の値 `self^` とは異なります。

## 中断できるサブルーチン

`yield^`・`_yield^`・`await^` によって yieldable かどうかを推論します。
yieldable な呼び出しは本体を実行せずコルーチンを返します。
関数にも yieldable な本体を書けますが、関数内で進めるコルーチンの由来などに制限があります。
詳細は[コルーチン](./coroutines.md)を参照してください。
