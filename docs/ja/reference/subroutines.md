# 関数と手続き

## 定義と署名

```text
f^引数:型, 引数:型 = 既定値 -> 戻り値型 { 本体 }
p^引数:型 -> 戻り値型 { 本体 }
```

`f^` は関数、`p^` は手続きです。どちらも値として束縛し、引数や戻り値にできます。
型注釈は推論できる位置で省略できます。関数・手続きの型には末尾の `;` が必要です。
定義の本体は波括弧で閉じます。

## 呼び出しと副作用

| 規則 | 関数 `f^` | 手続き `p^` |
| --- | --- | --- |
| 呼べるサブルーチン | 関数 | 関数と手続き |
| 名前への代入 | 自分の本体が作った名前・引数 | 外側の可変な名前も可 |
| テーブルの変更 | 自分の本体が作った範囲 | 外部のテーブルも可 |

局所テーブルに外部のテーブルを格納しても、その外部テーブルを変更する権限は得ません。
型検査は入れ子の由来も考慮します。
`fresh^` は呼び出しが新しい値を返す約束、`mutable^self^` は関数メソッドが受け手を変更する約束です。
この約束を持つメソッドを関数内から呼べるかも、値の由来に従います。

副作用を許す `p^` 型には、引数・戻り値などの条件が合う `f^` の値も適合します。
逆向きは認めません。`p^` 型の値を関数から呼ぶには、関数型への絞り込みが必要です。

## 引数と戻り値

引数は本体内の名前で、再代入できます。既定値と引数名は署名の型に含めません。
可変長引数は `...:型`、型を省略すれば `any^` です。
可変長引数は末尾にだけ書け、本体の `...` は受け取った値を集めた1つのテーブルです。
戻り値は `return^式` と書きます。

引数の既定値は、エディタが呼び出しを作るときの初期値です。**引数を省略可能にはしません。**
`f^x:number^ = 1 { x }` も、呼び出すときには必ず1引数を渡します。既定値は引数型と照合しますが、引数型の推論の根拠にはしません。
関数はすべての終了経路で値を返す必要があり、`nil^` を返す場合も `return^nil^` と明示します。
戻り値のない手続きの呼び出し結果は `nil^` という値ではなく「値なし」なので、束縛・引数・式には置けません。

関数の本体全体が式1つだけなら、その式を返します。
この規則は複数文の末尾や手続きには広がりません。複数文の関数では `return^` を明示します。
戻り値のない手続きの署名は `p^引数型;` で、戻り値の節を置きません。

## 複数の戻り値

```lhat
let^divmod = f^a:number^, b:number^ -> number^, number^ {
    return^a // b, a % b
}
let^q, r = divmod(7, 2)   # 3, 1
let^_^, m = divmod(9, 4)  # 1 だけを使う
```

`return^式1, 式2` は複数の値を返します。複数の値はタプルという1つの型として扱います。

- 戻り値の型は `-> 型1, 型2` とコンマで並べます。`-> (型1, 型2)` も同じ型です。
  エラーとの合併は括弧が必要です。[複数の値とエラー](./errors.md#複数の値とエラー)を参照してください。
- 受け取りは分解束縛 `let^q, r = 呼び出し()` です。名前の数と位置の数が一致しなければ型エラーです。
  使わない位置は `_^` で捨てます。呼び出し文として結果をすべて捨てることもできます。
- タプルを置けるのは戻り値の位置だけです。1つの名前への束縛、引数、テーブルの要素、
  別のタプルの位置、文字列補間の穴には置けません。1要素のタプルはなく、裸の単一型はその型です。
- 型が合えば、`return^呼び出し()` で別のサブルーチンのタプルをそのまま返せます。
- `pack^呼び出し()` は結果を配列テーブルにします。型は `t^{ 型1, 型2 }` で、タプルとは別の型です。
  逆に、テーブルを名前の列へ暗黙に分解することはありません。
- Lua と異なり、途中の呼び出しを1つの値に切り詰めたり、末尾の呼び出しを暗黙に展開したりしません。

### `nil^` との合併は括弧で意味が変わる

`,` は `|` より弱く結合するため、括弧の有無で `nil^` がかかる範囲が変わります。

| 戻り値の型 | 意味 | 受け取り方 |
| --- | --- | --- |
| `-> string^, number^\|nil^` | 常に2つの値。2つ目の位置だけが `nil^` を取りうる | `let^s, n = 呼び出し()` でそのまま分解できる |
| `-> (string^, number^)\|nil^` | 2つの値、または `nil^` 1つ | `??` で代わりのタプルを与えてから分解する |

```lhat
let^find = f^key:string^ -> (string^, number^)|nil^ {
    if^key = "a" {
        return^"a", 1
    }
    return^nil^
}
let^name, value = find("b") ?? ("none", 0)
```

後者は1つの名前にも、そのままの分解束縛にも受けられません。
値の数が呼び出しごとに変わるためです。`??` や `for^` の走査など、`nil^` を判別する構文で受けます。
テーブルの走査の `start()`・`resume()` もこの形の型を返します。
タプル全体と合併できるのは `nil^` とエラー型だけです。エラー型については[複数の値とエラー](./errors.md#複数の値とエラー)を参照してください。

## 引数への展開

呼び出しの引数の後ろに `...` を書くと、その値を複数の引数に展開します。
`...` を書かない限り展開しません。受け手が可変長引数を持っていても、暗黙には展開しません。

```lhat
let^three = f^a:number^, b:number^, c:number^ { a + b + c }
three(divmod(7, 2)..., 10)   # three(3, 1, 10)
three(1, divmod(7, 2)...)    # three(1, 3, 1)
```

| 展開する値 | 書ける位置 | 埋める引数 |
| --- | --- | --- |
| タプル | どこでも。1つの呼び出しに何度でも | 固定引数と可変長引数 |
| 列の要素型が分かるテーブル（`t^{ T[] }`） | 最後の引数だけ | 可変長引数だけ |
| 本体の `...`（受け取った可変長引数の転送） | 最後の引数だけ | 可変長引数だけ |

タプルは幅が型で決まっているため、位置をその場に書き並べたのと同じになります。
各位置は、それが埋める仮引数の型と照合します。位置の数が合わなければ引数の数のエラーです。
テーブルと転送の `...` は長さが実行時まで分からないため、可変長引数の部分にしか流せず、後ろに引数を続けられません。
受け取る側の `...` は、どの形で渡されても1つのテーブルです。

## 再帰と受け手

`this^` は現在実行中のサブルーチンです。束縛名に依存せず自己再帰できます。
`this^^` は字句上の1つ外側のサブルーチンです。
第一引数の `self^` はメソッドの受け手を表し、`値.メソッド()` で自動的に渡されます。
`Self^` は型の参照であり、受け手の値 `self^` とは異なります。

閉包は外側の名前の格納場所を共有して捕捉します。作成時の値のコピーではないため、その後の再代入も見えます。
ただし関数・手続きの副作用制限は捕捉後も変わりません。

## 中断できるサブルーチン

`yield^`・`_yield^`・`await^` によって yieldable かどうかを推論します。
yieldable な呼び出しは本体を実行せずコルーチンを返します。
関数にも yieldable な本体を書けますが、関数内で進めるコルーチンの由来などに制限があります。
詳細は[コルーチン](./coroutines.md)を参照してください。
