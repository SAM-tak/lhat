# 束縛とスコープ

## 宣言と再代入

| 形 | 意味 |
| --- | --- |
| `let^名前 = 式` | 再代入しない名前を導入 |
| `var^名前 = 式` | 再代入できる名前を導入 |
| `let^名前:型 = 式`、`var^名前:型 = 式` | 型注釈を付けて導入 |
| `名前 := 式` | 導入済みの名前へ再代入 |
| `対象 += 式` など | 読み・演算・書き戻しによる複合代入 |

`=` は宣言の初期値やテーブルの要素を導入する記号です。式の中の `=` は等値比較です。
再代入には `:=` を使い、未宣言の名前は作りません。
複合代入は `+=`・`-=`・`*=`・`/=`・`//=`・`%=`・`**=`・`..=` です。
メンバや添字を対象にした場合、受け手と添字は一度だけ評価します。
`?:=`・`?+=` などの `?` 付き代入は、対象が `nil^` でないときだけ右辺を評価して書き込みます。
不在なら右辺も評価しません。複数対象の代入は、書き込み前の値を使って右辺を評価します。

`let^` が制限するのは名前への再代入です。
その名前が指すテーブルの変更可否は、型、封印、関数の副作用規則などで別に決まります。

## 名前の見える範囲

名前は字句的なスコープで解決します。宣言の初期化子から、その宣言で作る新しい名前は見えません。
再帰で自分自身を参照するときは `this^` を使えます。
別名の宣言はスコープ全体で見えるため、遅延実行される関数本体どうしの相互再帰を書けます。
ただし、宣言が実行されて値が入る前に、その値を直接読み出すことはできません。
同じフレームで同じ名前を重ねて宣言することはできません。
内側のスコープから外側の名前を参照することは、書き換える権限を意味しません。
特に `f^` から外側の名前への代入はできません。

`it^` は `for^` や `catch^` が導入する焦点、`self^` はメソッドの受け手です。
`it^^`・`self^^`・`this^^` のような綴りは、それぞれ対応する外側の文脈を参照します。
`this^^` は字句上の外側であり、呼び出し元のスタックを指すものではありません。

| スコープ指定 | 探し始める位置 |
| --- | --- |
| `$名前` | 翻訳単位の先頭 |
| `$$名前` | 外側から数えて1段内側 |
| `$^名前` | 現在から1段外側 |
| `$^^名前` | 現在から2段外側 |

指定子と名前の間に空白を置けません。指定した位置になければさらに外側を探します。
段数は名前のスコープを開くブロックで数え、テーブルリテラルや補間の穴は数えません。
存在するスコープの外を指す指定はエラーです。

## メンバの導入と変更

`var^ t.member = 値` はメンバの導入、`t.member := 値` は既存メンバの再代入です。
テーブルリテラル内では `member = 値`、`[キー式] = 値` と書きます。
メンバを書き換えると、そのテーブルを共有する参照からも変更が見えます。
`let^t.member = 値` は使えません。`let^` で束縛したテーブルへの追加も含め、具体例は[構築済みテーブルへのメンバ追加と更新](./objects.md#構築済みテーブルへのメンバ追加と更新)を参照してください。

## メンバの定義と更新を兼ねる形

`var^t.member := 値` は、メンバがなければ導入、あれば更新する形です。
`var^t.member = 値` は導入専用です。裸の `t.member := 値` が新しいメンバを宣言するわけではありません。
この追加は通常のテーブルに対する操作で、定義やインスタンスの構造へ後付けするものではありません。
型注釈を経由した構造型では、その注釈に基づいて可否を判定します。

## 多重代入の評価

複数の書き先では、受け手・添字・右辺を読み切ってから書き込みます。`a, b := b, a` で値を交換できます。
`a, b += x, y` も各位置に演算します。`?:=`・`?+=` の不在判定は位置ごとで、ほかの位置は更新できます。

## 複数の値と分解

`let^a, b = 式1, 式2` は複数の束縛を導入します。
右辺が1つのタプルを返す呼び出しなら、`let^a, b = 呼び出し()` は分解束縛です。
名前の数とタプルの位置の数は一致しなければなりません。
テーブルを名前の列へ暗黙に分解することはありません。テーブルの要素は添字で取り出します。
入れ子の分解はありません。余分な値を暗黙に切り捨てたり、不足分を自動で埋めたりもしません。

`_^` は値を捨てる受け皿です。値を参照できる名前を導入しません。
型注釈が必要な位置では `_^:型` と書けます。

## 構文が導入する名前

引数は本体内で再代入できます。`with^` が導入する名前は再代入できません。
数値反復の `for^i from^…` の焦点や、走査が束縛する名前も本体から再代入できません。
条件付き反復で自分で更新する焦点には `for^var^i = …` を使います。

言語が用意する暗黙のグローバル変数はありません。翻訳単位の名前、取り込んだ名前、ホストの初期束縛を使います。
