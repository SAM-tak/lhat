# アプリケーションに組み込む

L^ を組み込むときは、ホストアプリケーションが起動、イベントループ、リソースの寿命を管理します。
L^ 側にはアプリケーションの API を公開し、必要なタイミングでスクリプトの処理を呼び出します。

このガイドは、C / C++ のアプリケーションへ初めて組み込む人を対象にしています。
言語の構文を一通り学ぶ前でも、動くホストを作ってから必要な機能を追加できます。

## 最初に作るもの

[最小のホストアプリケーション](./getting-started.md)では、次の往復を実装します。

```text
ホストが app.report を登録
    ↓
main.lh を型検査・コンパイル・初期化
    ↓
ホストのフレームループ → スクリプトの update(dt)
    ↓
スクリプト → ホストの app.report(elapsed)
```

例は標準ライブラリに依存しません。ファイルを読み、API を登録し、3フレーム実行して終了する C プログラムです。
ソースは [sample/embedding](https://github.com/SAM-tak/lhat/tree/main/sample/embedding)にあります。

## 組み込みの順序

| 段階 | ホスト側で行うこと | 読むページ |
| --- | --- | --- |
| 1 | ライブラリのリンク、型検査、初回の実行 | [最小のホスト](./getting-started.md) |
| 2 | 関数、エンジンのオブジェクト、値型を公開 | [ホスト API と型](./host-api.md) |
| 3 | コールバック、GC、実行予算、終了を管理 | [実行と寿命](./runtime.md) |
| 4 | エディタにホストの型を伝え、実行エラーを表示 | [開発環境と診断](./tooling.md) |
| 5 | スクリプトを再読込し、配布形式を決める | [リロードと配布](./deployment.md) |

実際の C コードの書き方は、[標準ライブラリのバインド実装](./binding-examples.md)で説明します。
個々の C 関数は [C API リファレンス](../api/index.md)から調べられます。

## ホストが所有する二つのもの

`LhatProgram` は、読み込んだソース、型検査の結果、コンパイルしたコード、ホスト API の登録を所有します。
`LhatMachine` は、実行スタックと GC 管理の値を所有します。
同じ Program のコードを複数の Machine で実行できますが、Machine が作った値をそのまま別の Machine へ渡すことはできません。

基本の順序は、**Program 作成 → API 登録 → 型検査 → コンパイル → Machine 作成 → install → 実行**です。
終了時は **Machine → Program** の順に破棄します。ホストの API が参照するエンジンやコンテキストは、Machine の後始末が終わるまで生かしてください。

このガイドと C API は `main` に追従します。L^ のヘッダとライブラリ、および組み込み先のバージョンを揃えてください。
